RunPod 유료 작업을 시작하기 전 승인 자료를 준비해줘. 이 메시지는 생성·결제·삭제 승인이 아니야.
먼저 docs/12_RUNPOD_PLAYBOOK.md와 reports/RUNPOD_APPROVAL.md를 확인해줘. 콘솔/CLI 접근이 없으면 필요한 비밀값 제외 항목만 내가 확인할 수 있게 안내하고, 확인하지 않은 값은 미확인으로 남겨줘.

제시할 항목:
- 실제 확인 시각, 계정 잔액/기존 유료 리소스 확인 여부, GPU 종류·개수 1·tier·region·시간당 요금.
- container/volume 용량과 실행·중지 시 요금, 전체 SSH·파일 전송·포트 터널 가용 여부.
- 설치/다운로드/파일럿/학습/평가/유휴/실패/백업을 포함한 최대 실행시간과 총비용. GPU $7 + 기타 $1, 잔액 여유 $2 계획과 비교.
- 예산 계산기의 실제 입력과 출력. 계산기는 종료 제어가 아님을 명시.
- 소량 파일 왕복·SHA 검증과 학습 어댑터/로그 백업 위치. 종료/삭제 전에 복구 확인.
- 시간/예산 초과 전에 어떤 승인된 방식으로 멈출지, stop과 terminate/볼륨 삭제 중 어디까지 승인을 요청하는지.

reports/RUNPOD_APPROVAL.md에 견적만 먼저 기록하고 approved=false를 유지해줘. 실제 사용자 승인을 받은 경우에만 승인한 범위/시각을 기록해줘. 자동충전, Vast 전환, 두 번째 Pod는 별도 승인 없이 하지 마. API 키와 SSH 개인키는 출력하지 마.
