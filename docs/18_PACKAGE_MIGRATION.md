# 18. 패키지 전환 기록 — v3 기술 계획 → v4 Claude Code 작업 패키지

## 버전 의미
v4.0은 구현 도구와 배포 폴더를 바꾼 패키지 버전이다. `docs/14_FINAL_AUDIT.md`의 v2 → v3 기술 검토 이력은 보존한다. 문서 제목의 v3는 해당 기술 검토의 기준을 뜻하며, 이전 작업 도구를 다시 사용하라는 지시가 아니다.

## 변경
- 배포 루트: `invoiceguard-po/`. 한 번만 압축 해제하면 해당 폴더가 생긴다.
- 프로젝트 지침: 루트 `CLAUDE.md`와 최소 `.claude/settings.json`.
- 시작·재개·유료 승인·모델/릴리스 프롬프트를 Claude Code용으로 제공.
- 현재 실행 상태·작업표·세션 인계·RunPod 승인 기록을 분리.
- 기존 계약 검사 파일명을 `verify_contracts.py`로 정리. UTF-8 읽기/쓰기 명시.
- `verify_claude_pack.py`와 배포 해시 검사 추가. 검사 전용 의존성 파일 제공.
- 과거 기술 감사 문서는 보존하되 active 문서의 작업 도구와 파일 참조는 갱신.
- 모든 배포 파일의 manifest를 재작성하고 ZIP 내부 경로/해시를 검사.

## 변경하지 않은 것
영어, 합성 데이터임을 명시, 모델 후보, QLoRA 방식, PUBLIC_CANONICAL/TRADE_RAW 분리, 데이터 분할, M0/M1 공정 비교, GPU 16GB 로컬+RunPod 우선, $7/$1/$2 예산 계획, 사람 승인, G0–G7 게이트.

## 아직 하지 않은 것
제품 구현, 전체 데이터 다운로드, 이미지 정답 감사, RunPod 연결/견적/잔액 조회, GPU 학습·서빙·모델 평가, Claude Code CLI 직접 실행.
기존 `reports/SOURCE_VERIFICATION.json`은 2026-11-13의 이전 공개 출처 확인 기록이며 이번에 재수행했다는 의미가 아니다. 새 Claude Code 공식 출처 확인은 `docs/17_CLAUDE_CODE_WORKFLOW.md`에 별도로 기재한다.

## 기존 작업이 있는 사용자
이 ZIP으로 기존 폴더를 덮어쓰지 않는다. 별도 폴더에 푼 뒤 구현 코드와 문서를 비교하고 필요한 지침만 통합한다. 기존 완료 기록·유료 승인·실험 증거를 초기 상태 파일로 덮어쓰지 않는다. 이번 패키지의 초기 상태는 새 프로젝트를 위한 것이다.
