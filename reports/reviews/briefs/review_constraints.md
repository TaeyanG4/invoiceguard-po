## 평가 범위 — 하드웨어·시간 한계로 불가능한 항목은 채점·제안에서 뺀다 (사용자 지시, 2026-11-15)

이 프로젝트는 아래 자원 안에서 진행한다. 이 한계 때문에 **할 수 없는 작업**은 감점 사유로 삼지 않고, 개선 제안에도 넣지 않는다.
대신 그런 한계를 README·보고서에 **정직하게 적었는지**만 본다(적지 않았거나 과장했다면 그것은 지적한다).

**자원**
- 로컬 PC 1대: RTX 4070 Ti SUPER 16 GB, Windows 10, NVIDIA 드라이버 561.17(CUDA 12.6).
- 유료 GPU: RunPod Pod 한 번에 1대, 실제 견적을 사용자가 승인한 뒤에만. GPU 계획 예산 $7(지금까지 추정 약 $2.16 사용).
- 기본 모델은 Qwen3-VL-2B로 끝낸다(사용자 결정). 큰 모델은 돌리지 않는다.

**평가에서 제외하는 것 (감점도, 제안도 하지 않음)**
| 항목 | 이유(기록) |
|---|---|
| fp32 등 고정밀 학습, 오래 걸리는 정밀도 전수 비교의 확대 | 16 GB에 2B 전체 정밀도 학습이 들어가지 않음. int8 추론은 문서당 43–69초(`reports/quant/`) |
| 로컬 bf16(비양자화) LoRA 학습 | 15.8 GB까지 차 공유 메모리로 넘침, 358초/step(80 step ≈ 8시간) → L40S에서 1회 수행(`reports/runpod2/train_m1_bf16lora_l40s.json`) |
| 전체 파인튜닝, 2B보다 큰 모델(4B·8B·32B) 학습 | VRAM·예산 한계, 사용자 결정 |
| 32B 등 큰 교사 모델로 라벨 만들기 | L40S에서도 KV 캐시 부족·15 tok/s(`handoff.md` 실행 2), 사용자 결정 |
| 멀티 GPU(DeepSpeed/FSDP) | 로컬 GPU 1장, 유료 Pod도 1대 원칙 |
| 로컬 vLLM | 드라이버 CUDA 12.6 < vLLM 0.11.2 요구 12.9 → RunPod에서만 측정 |
| 사람이 직접 라벨링하는 실문서 데이터 구축 | 라벨 작업 인력 없음 → 라벨이 있는 CORD v2 사용 |
| 시간이 오래 걸리는 대규모 반복(많은 seed·하이퍼파라미터 탐색) | 로컬 GPU 하나로 직렬 실행, 유료 예산 소액 |

**개선 제안의 조건**
- 로컬 16 GB GPU에서 몇 시간 안에 끝나거나, 승인된 Pod 1대에서 남은 예산(약 $4.8) 안에 끝나는 것만 제안한다.
- 제안마다 대략의 시간과(유료면) 비용을 적는다.
